## 2024-10-12 - FastAPI Static Response Optimization
**Learning:** Returning standard python dicts for static endpoints in FastAPI adds significant internal overhead (~25% overhead in local testing). Even when returning a simple static response like `{"status": "healthy"}`, FastAPI runs it through `jsonable_encoder` and validation steps.
**Action:** For highly-queried static endpoints (like liveness/readiness probes), return a new `JSONResponse(content={"status": "healthy"})` directly instead of a `dict` to bypass serialization overhead. Use `@app.get(..., response_model=...)` to keep OpenAPI docs correct, and update the function return type hint to `-> JSONResponse`. Avoid pre-instantiating a global singleton `JSONResponse` object to prevent subtle bugs with global state mutation by middlewares.
